PBpark Weball について
PBpark Weball
P2P Web Meeting Tool

PeerJS（WebRTC）を使用した暗号化Web会議アプリケーションです。

  • サーバーを通過しない安全なP2P映像通信。
  • ワンクリックURL共有によるかんたん参加。
  • プロフィールのファイルピッカーアバター対応。
